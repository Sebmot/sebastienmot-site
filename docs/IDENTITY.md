# Identité visuelle — Sébastien Mot

Référence pour le site et les visuels LinkedIn (2026).

## ADN

- **Positionnement** : entrepreneur belge (Bruxelles), argent et décisions pour dirigeants de PME — terrain, pas théorie.
- **Ton** : direct, sans filtre, pair à pair (« d'entrepreneur à entrepreneur »).

## Palette

| Rôle | Valeur | Usage |
|------|--------|--------|
| Fond affiche | `#05080f` → `#000` | Hero, convictions, Nezo, contact, footer |
| Bleu électrique | `#2f6fe0` / `#3d8bff` | Accents typo, halos, CTA secondaires |
| Magenta | `#e0338f` / `#e838a0` | Contrepoint glow, accents « humains » |
| Texte sur fond sombre | `#eef2f7` (corps), `#fff` (titres) |
| Fond éditorial clair | `#f4f7fa` | Posts, stats, projets (respiration) |
| Encre | `#030d1b` | Texte sur fond clair |

## Typographie

- **Affiche / marque** : Montserrat (uppercase, graisse 700–800) — logo, kickers, hero, cartes sombres.
- **Lecture** : Manrope — corps, listes, extraits.
- **Méta** : DM Mono — dates, labels, filtres.

## Motifs signature

- Halos radiaux bleu (bas-gauche) + magenta (bas-droite) sur fond noir.
- Lignes verticales fines aux bords des blocs « affiche » (optionnel).
- Cartes claires type magazine pour le flux posts ; cartes affiche pour convictions et hero.

## Références d’ambiance

- Visuels LinkedIn Sébastien Mot (navy + glow).
- Affiches éditoriales fintech / business media (FT, Monocle) — typo forte, peu de décor inutile.
- Sites 2026 : mesh gradients subtils, glass léger, motion courte et respectueuse de `prefers-reduced-motion`.
